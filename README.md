# Bilibili as Music Player：在 Codex 里点歌，让音乐陪你写代码

[中文](README.md) | [English](README.en.md)

**聊天点歌，悬浮球控制。不必为了换一首歌，离开正在进行的工作。**

## 背景
许多人喜欢在写代码时听歌：用熟悉的旋律陪伴工作，用合适的节奏进入专注状态。使用 Codex 时，我们也希望音乐自然地融入工作，让点歌和切歌尽量少打断思路。

## 现状
通常，我们需要另外打开音乐网站或客户端，搜索歌曲、选择版本、开始播放。想换一首歌时，再切回播放器操作，然后回到 Codex 继续工作。

## 缺陷
- **点歌受到限制。** 一些平台的歌曲需要会员才能完整播放，很多音乐我们未必能够听到。
- **曲库未必符合口味。** DJ 改编、翻奏、混音和新流行的版本不一定能在音乐平台找到。例如，想听最近流行的《琵琶曲 DJ》，往往得上b站。
- **操作打断工作。** 搜索、点歌、切歌需要在不同窗口之间来回操作，它们让我们觉得厌烦，分散我们的注意力

## 解决方法
Bilibili as Music Player 让你直接在 Codex 聊天框中搜索 B 站视频，选择喜欢的版本，播放其中的音频。无需打开 B 站网页或另一个音乐客户端，也无需让 Agent 操作浏览器。
- **聊天就是点歌入口。** 说出歌名、版本或 BV 号，由 Codex 调用插件完成搜索与播放。
- **看清候选再选择。** 候选展示标题、UP 主、时长、发布日期、BV 号、视频链接和封面，方便分辨不同版本。
- **常用控制随手可达。** 独立悬浮面板提供暂停／继续、上一首／下一首、单曲循环、顺序播放和音量调节；不用每次都发消息等待 Agent。
- **悬浮球。** 面板可以收起为可拖动的悬浮球，点击后展开，减少屏幕占用。
- **切换聊天也能继续听。** 播放与当前聊天分开管理，切换 Codex 聊天不会中断音乐。
当前版本面向 **Windows 本机的 Codex**，播放音频由本机设备输出。搜索与播放面向无需登录的公开视频，能否访问仍取决于 B 站的视频权限与服务状态。

### 源码公开，行为可以检查
本仓库提供插件源码，搜索、播放控制和悬浮面板的实现都可以直接阅读与审查。插件不读取浏览器 Cookie；候选封面会缓存在本机。运行依赖的来源与许可材料见 [第三方软件声明](THIRD_PARTY_NOTICES.md)，方便检查插件使用了哪些外部程序。

## 使用实例：在聊天中点播
### 搜索，选一个喜欢的版本

> 你：搜索琵琶曲 DJ，让我选择版本。
>
> Codex：展示带编号的候选视频及其信息、封面。
>
> 你：播放第 2 个。

模糊搜索不会自动播放第一条，你选择之后才开始播放。每次新搜索会更新候选列表。

### 直接播放指定视频
> 播放这个 BV 号对应的视频音频。
>
也可以直接发送 B 站视频链接，指定要听的版本。

### 用一句话控制播放
- “暂停”／“继续”
- “音量调到 40”
- “上一首”／“下一首”
- “开启单曲循环”／“开启顺序播放”
- “现在播放到哪里了？”
“停止播放”按暂停处理，继续时从原进度播放。

### 按播放历史切歌
“上一首”“下一首”和顺序播放都沿实际播放历史移动，不会跳到未点播的搜索候选。再次点播同一个 BV 视频，会把它移到历史末尾，历史中只保留一份。
顺序模式在当前视频结束后播放历史中的下一首，到历史末尾停播；单曲模式循环当前视频。两种模式都关闭时，播放结束即停。

### 用悬浮球随手控制
连接播放服务后，桌面会出现悬浮面板。你可以直接点击按钮暂停、继续、切歌或调整播放模式，也可以拖动音量滑槽。滑槽获得焦点后，左右方向键每次调整 1% 音量。
点击面板右上角按钮可收起为悬浮球；拖动小球调整位置，点击小球重新展开。收起面板不会影响播放。偏好查看尚未开放，当前按钮不可用。

## 安装
**Windows EXE 安装包将通过本仓库的 GitHub Releases 提供下载。** 下载入口将在正式发布后补充。

本仓库用于提供源码与供人审阅。安装器自动准备运行依赖，首次安装需联网获取固定版本的 mpv；普通用户无需手动配置 JSON 或 MCP 命令。
