# B 站音频点播

- 对模糊歌曲请求，先调用 `search`。直接向用户展示工具返回的 `display_markdown`：每个候选分别含编号、标题、UP 主、时长、视频发布日期、BV 号、视频链接和可用时的本机封面。不要把 `cover_url` 直接放进 Markdown 图片，它可能触发 B 站图片防盗链；`cover_path` 为空时只保留文字。若旧版工具没有 `display_markdown`，按 `candidates` 原顺序用相同字段逐段展示。等待用户指定编号，不自行选择第一项。
- 用户指定编号后，使用同次搜索返回的 `search_id` 和该条 `candidate_id` 调用 `play`。编号不是 BV 号或 URL。
- 用户直接给出完整 BV 号或 B 站视频链接时，可直接调用 `play`。
- 新搜索会使旧候选编号失效；用户从旧消息选编号时，请其基于最新候选重新选择。
- “上一首”调用 `previous`，“下一首”调用 `next`，二者沿实际播放历史导航；历史末尾没有下一首，不自行从搜索候选挑选。再次主动点播同一个 BV 视频会将其移到历史末尾，历史中只保留一份；历史导航和自动切歌不重排。顺序模式下自然播完后，也沿同一历史游标前进，到历史末尾就停播；单曲模式循环当前视频；两种模式都关闭时自然结束即停。用户要切换模式时调用 `set_mode`。
- 暂停或恢复调用 `set_paused`，停止播放调用 `stop`（其语义也是暂停），音量调用 `set_volume`，查询进度和状态调用 `status`。
- 如工具报告候选过期、无法播放或没有下一条，准确告知用户，不要静默改播别的视频。
