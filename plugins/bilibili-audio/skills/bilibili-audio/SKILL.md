# B 站音频点播

- 对模糊歌曲请求，先调用 `search`。按工具返回的原顺序，在聊天中展示候选编号、标题、UP 主和时长，等待用户指定编号；不要自行选择第一项。
- 用户指定编号后，使用同次搜索返回的 `search_id` 和该条 `candidate_id` 调用 `play`。编号不是 BV 号或 URL。
- 用户直接给出完整 BV 号或 B 站视频链接时，可直接调用 `play`。
- “下一首”调用 `next`，含义是本次已选搜索结果中的下一候选；自然播放结束后不要自动调用。
- 暂停或恢复调用 `set_paused`，停止播放调用 `stop`，音量调用 `set_volume`，查询进度和状态调用 `status`。不要将“停止”解释为“暂停”。
- 如工具报告候选过期、无法播放或没有下一条，准确告知用户，不要静默改播别的视频。
